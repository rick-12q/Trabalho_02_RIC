# Projeto 2 — RIC

Projeto de IoT com ESP32, API REST HTTP, simulador, banco de dados e dashboard Node-RED.

## Estrutura

- `Code/`: código-fonte do simulador, backend, frontend, firmware e banco de dados.
- `Node_red/`: exportação JSON do fluxo Node-RED.
- `Relatorio/`: relatório acadêmico, arquivos TeX e PDF.

## Tecnologias

- ESP32 e Arduino/C++
- Python e FastAPI
- PostgreSQL
- Node-RED
- API REST HTTP
