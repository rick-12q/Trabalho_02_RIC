# ESP32 Simulator

Simulador do ESP32 executado no PC para desenvolvimento e testes sem hardware.

O simulador deverá reproduzir o comportamento e o contrato REST previstos para o ESP32 real.

Responsabilidades futuras:

- Simular BME280
- Gerar temperatura, umidade e pressão
- Simular botão físico
- Simular LED
- Expor API HTTP do dispositivo
- Enviar telemetria para o backend
- Permitir testes locais antes da utilização do ESP32 físico
